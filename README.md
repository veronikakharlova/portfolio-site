# Портфолио — быстрый старт

## Что в этой папке

- `index.html` — главная страница сайта
- `projects/` — сюда добавляются страницы отдельных проектов
- `projects/project-template.html` — заготовка для новой страницы проекта
  (уже с нужным дизайном, шрифтами и стилями — просто наполните текстом)
- `CLAUDE.md` — описание проекта для Claude Code (он прочитает его
  автоматически, ничего делать с этим файлом не нужно)

## Как начать работу в Claude Code

1. Распакуйте архив в удобное место на компьютере, например
   `Документы/portfolio-site`
2. Откройте терминал и перейдите в эту папку:
   `cd путь/до/portfolio-site`
3. Запустите `claude`
4. Первым делом можно попросить:
   «Открой index.html в браузере и покажи скриншот, чтобы свериться
   с дизайном» — или сразу переходить к задачам

## Как добавить страницу проекта

Например, для проекта «Мессенджер с высоким уровнем шифрования»
(ссылка на неё уже стоит в index.html — `projects/messenger.html`):

> «Возьми projects/project-template.html за основу и создай
> projects/messenger.html — это кейс про мессенджер с высоким уровнем
> шифрования для закрытого контура коммуникаций (2025, NDA). Заполни
> текстом: задача, процесс, результат — реалистичными формулировками,
> без конкретных цифр, которые я не подтверждала»

Так же можно попросить сделать все шесть страниц проектов за один раз,
перечислив их в одном сообщении.
